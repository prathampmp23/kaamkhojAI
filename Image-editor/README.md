# Image Editor

A simple in-browser image editor built with HTML, CSS, and JavaScript. This project provides basic image manipulation functionalities right in your web browser.

## Features

- **Image Adjustments:** Modify brightness, saturation, inversion, and grayscale of your images.
- **Real-time Previews:** See the changes you make to your image in real-time.
- **Save Your Image:** Download the edited image to your device.

## Tech Stack

- HTML5
- CSS3
- JavaScript
